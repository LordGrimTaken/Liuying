Install

  1. Download the APK

    Tap the button above. If your browser warns that this type of file can be harmful, choose to keep it.

  2. Allow installs from unknown apps

    When Android asks, open Settings and enable “Install unknown apps” for your browser or file manager. You only do this once.

  3. Open the file and tap Install

    Open it from your notifications or Downloads folder, then confirm the prompt.

Updates

Liuying checks this page for a newer version when it starts, at most every six hours, and from You › About › Check for updates. When one exists you can download it inside the app. It is checked against the checksum above, then handed to Android to install over your current copy. Your sources, shelf and progress stay. You can turn automatic checks off in settings.

Updates only install over copies that came from this site, because they are signed with the same key.
